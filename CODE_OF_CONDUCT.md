# Code of Conduct

diMail follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, welcome people of every background and level of experience, and focus on what is best for the project and its users. Harassment, insults, personal or political attacks, and publishing others' private information are not tolerated.

## Scope

This code applies in every project space (issues, pull requests, discussions, reviews) and when someone represents the project elsewhere.

## Reporting

Report unacceptable behavior privately to the project maintainer through the contact on [their GitHub profile](https://github.com/tommasoseita). Every report will be reviewed and handled confidentially. Maintainers may remove comments, commits or contributions, and temporarily or permanently ban contributors, following the Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
